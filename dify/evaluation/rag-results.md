### 真实请求结果

- Service API 返回 HTTP 200，SSE 包含 `workflow_started`、`node_finished`、`message`、`message_end` 和 `workflow_finished`。
- 固定节点 `结构化建议` 返回对象型 `structured_output`，包含回答可信状态、3 个追问和候选行动。

- InTeam API 成功保存带服务端 ID 的候选建议；接受后主题为 `exploring`，完成行动后主题为 `completed`。
- 本次是发布冒烟验证，不等同于 60 条知识回答评测。
