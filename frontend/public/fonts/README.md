# Optional MiSans font

MiSans-VF.ttf is not distributed with this repository because the official
MiSans license prohibits further distribution of the font software.

To use MiSans locally:

1. Download it from https://hyperos.mi.com/font and review the license.
2. Place the variable font at frontend/public/fonts/MiSans-VF.ttf.
3. Keep a visible software notice that MiSans is used.

The UI falls back to the system sans-serif stack when the file is absent.
