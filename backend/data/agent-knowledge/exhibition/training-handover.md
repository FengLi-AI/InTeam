# 新讲解员上手准备与交付清单

版本：2026-09-19。适用对象：青禾能源探索馆讲解与接待人员。

首次讲解前，建议先阅读主线和三项展项资料，熟悉操作限制，再进行一次按目标时长计时的口头试讲。请带教人员核对事实表达与参观路线；AI 草稿只作准备材料，不代表已经完成带教确认。

交付准备包建议包含：讲解对象和时长、讲解主线、分段讲解稿、互动问题、操作提醒、资料缺口与待确认事项。未提供的票价、预约规则、馆长姓名、精确设备型号等事项保留待确认。

讲解员可以把“完成一次计时试讲”“向值班人员确认设备状态”加入个人计划，是否执行及何时完成由本人确认。InTeam 不自动通知带教人员，不自动安排参观，不把勾选任务完成等同于实际掌握知识。
