# 新讲解员前三次学习与试讲安排

版本：2026-09-19。下列安排是培训建议，具体时间由带教与学员确认。

## 第一次：认识主线

阅读 hall-overview 和 exhibits-guide。能用自己的话解释三段主线和三个核心展项。输出一张讲解顺序清单，标出不理解的术语。暂不要求背诵完整讲解稿。

## 第二次：观察与准备

阅读 operation-rules、reception-process 与 audience-guide，现场观察带教讲解，记录观众提问。选择一种观众类型准备讲解稿，列出需要核实的设备状态与接待条件。

## 第三次：计时试讲与反馈

按目标时长进行一次计时试讲。带教重点检查事实准确、表达易懂、衔接自然和操作边界四项。先指出具体问题与可修改段落，再安排复练。不采用 AI 自动评分来认定上岗资格。

## 记录方式

保留本次目标、采用的稿件版本、试讲实际时长、带教反馈和下一次改进事项。练习完成由学员记录，是否具备独立接待条件由相应负责人确认，两者不能等同。
