# 三个核心展项：知识信息与讲解重点

版本：2026-09-19。适用对象：青禾能源探索馆讲解与接待人员。

“风从哪里来”：观众通过风能互动台观察气流带动叶片运动，再带动小型发电装置点亮指示灯。它演示风的动能向电能的转化；指示灯亮度只能作现象观察，不能直接当成实际发电效率或定量发电功率。操作边界另见 operation-rules。

“阳光变电能”：通过光源照射太阳能电池板，让观众观察电表示数的变化，说明光伏发电将光能转化为电能。它不是靠把水烧开产生蒸汽发电。光照强度、照射角度变化会影响演示读数。本展项不提供真实城市发电量推算依据。

“城市能量账本”：屏幕呈现家庭照明、空调、交通三个示例用能场景，让观众比较不同用能习惯。屏幕数字为教学示例，不是城市真实统计。讲解可以引导观众提出随手关灯、合理使用空调等节能做法，不承诺固定节能百分比。

讲解员应区分展项事实、演示现象与个人建议；没有资料支持的数据、荣誉、设备参数不补写。
