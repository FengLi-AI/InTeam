# 青禾能源探索馆：展厅主线与参观路线

资料版本：2026-09-19。适用对象：青禾能源探索馆讲解与接待人员。

青禾能源探索馆服务公众科普。讲解主线为“认识能源—理解转化—探索节能”，让观众能说明能源如何变为日常可用的电，以及个人可以如何节能。

建议参观顺序：序厅“身边的能源”→“风从哪里来”风能互动台→“阳光变电能”光伏展台→“城市能量账本”→结束交流。该顺序是讲解建议，不是强制动线。

普通讲解可压缩为 10 分钟，优先覆盖三个核心展项并留出结束提问。详细科学信息见 exhibits-guide；互动装置的实际操作要求必须另外核对 operation-rules，不能仅凭本概览判断。

本资料没有馆内实时客流、当日设备状态、票价、预约名额、年度发电量、设备型号或特殊接待承诺，相关问题应向现场负责人确认。
