# 团体接待流程与讲解前核对

版本：2026-09-19。适用对象：接待人员、讲解员和当班负责人。

## 接待前

核对预约方提供的到馆时间、观众类型、预计人数、讲解时长、联系人和特殊需求。预约信息不完整时先向接待负责人补充确认，不能把口头意向当作已确认预约。票价、开放时间、预约入口与剩余名额由正式发布的运营信息提供，本手册不另行规定。

## 开讲前

讲解员向值班人员确认所经展项是否正常开放，核对临时封闭区域与疏散指引。设备尚未完成检查时可以先准备口头讲解，不能承诺一定能体验装置。团队人数需要分组时，由现场负责人结合空间条件决定，不擅自设定固定人数上限。

## 讲解中

先介绍主线与预计时长，提醒观众跟随路线、保持通道畅通。到达互动区后先说明如何参与及操作边界。观众提出资料外问题时，记录具体问题，并说明需要确认，不以猜测代替回答。

## 接待结束

在结束区回顾“能源来源—能源转化—日常节能”，留出提问时间。记录未解答问题、设备异常与用户反馈，交给对应负责人。对外回复时间应由负责人确认，讲解员不能随意承诺。
