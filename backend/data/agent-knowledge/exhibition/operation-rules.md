# 互动展项操作须知与异常处理

版本：2026-09-19。适用对象：青禾能源探索馆讲解与接待人员。

风能互动台：讲解员先口头说明再示范；观众只能使用台面标识的交互区，不得触摸叶片或拆卸透明罩。中学生可在工作人员看护下依次体验；资料没有最低年龄、身高或固定人数上限，不得自行承诺。

光伏展台：仅工作人员调整演示光源，观众可观察电表，不自行接触灯具、电线或电池板接线。

城市能量账本：观众可点选屏幕上的用能情境；不要把教学数据解释成真实城市数据。

任何装置出现异响、发热或响应异常时，立即停止该装置体验，提示观众退至展项标识的等待区，并通知现场值班人员；讲解员不能自行检修。没有设备当前运行状态时，讲解稿只能写“确认设备正常后可演示”，不能声称已检查完成。
