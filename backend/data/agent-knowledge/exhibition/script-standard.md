# 讲解稿编写规范与事实核对

版本：2026-09-19。适用于日常讲解、团体接待与上岗试讲。

## 稿件结构

稿件开头注明受众、目标时长、讲解主线和资料版本。正文按“开场—展项介绍—观察或互动—衔接—总结”组织，每段给出建议时长。口语稿使用短句，专有名词首次出现时附通俗解释。

## 表达边界

风能展项可解释动能转化，不承诺装置效率。光伏展项解释光能转为电能，不混同蒸汽发电。城市账本的数字是教学示例，不能用于推算当地真实用电量。未经资料支持的设备型号、技术排名、获奖情况、碳减排量和参观承诺均不补写。

## 互动设计

优先使用“先猜测—再观察—再解释”的顺序。互动不是必须操作装置：设备不可用时，可以改为口头提问、观察展板或讨论生活场景。是否开放操作由现场状态和操作规范决定。

## 核对与更新

稿件完成后对照展项资料核对事实，对照操作须知核对互动权限。需要改变事实、制度或公开数据时先由资料负责人确认。表达建议可以优化，但不能因此改变知识信息。计时试讲后再调整篇幅；仅靠字数估算不能保证实际讲解时长。
