# 项目架构说明

本文档介绍公司前端项目的整体架构与技术选型。

## 技术栈

前端统一使用 React 18 + TypeScript，构建工具使用 Vite。状态管理使用 Zustand，请求库使用 Axios。UI 组件库使用 Ant Design。样式方案使用 CSS Modules 配合 Tailwind CSS。

## 代码仓库结构

monorepo 使用 pnpm workspace 管理，包含 packages 目录下的共享组件库、utils 工具库和 apps 目录下的各业务应用。共享组件放在 packages/ui，通用工具放在 packages/utils。

## 模块划分

业务按功能域划分模块，每个模块包含 pages、components、hooks、services 四个目录。跨模块复用逻辑抽到 packages 下的共享包。

## 环境说明

开发环境使用本地代理转发到测试环境接口，测试环境和预发环境分别部署在独立域名，生产环境由运维统一发布。
