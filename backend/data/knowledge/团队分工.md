# 团队分工

本文档介绍开发团队的部门分工与协作对接方式。

## 前端组

负责所有 Web 端和 H5 页面的开发，包括组件库维护、性能优化和埋点接入。前端组负责人是小张。

## 后端组

负责接口开发、数据库设计和微服务维护。前后端联调时由后端提供接口文档，前端按文档对接。后端组负责人是小李。

## 测试组

负责功能测试和回归测试。需求开发完成后提交测试，测试通过后才能发布。测试组负责人是小王。

## 设计组

负责产品视觉设计和交互稿输出，设计稿统一放在蓝湖平台。前端开发前需从蓝湖获取标注和切图。设计组负责人是小赵。

## 报销与考勤

日常报销和请假统一在飞书审批中提交，考勤通过飞书打卡记录。遇到流程问题可以咨询 HR 小周。
