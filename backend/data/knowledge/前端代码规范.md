# 前端代码规范

本文档是团队前端代码的统一规范，所有前端项目必须遵守。

## 命名规范

组件文件名使用 PascalCase，例如 `UserCard.tsx`。普通工具函数文件使用 camelCase，例如 `formatDate.ts`。变量和函数名一律使用 camelCase，常量使用 UPPER_SNAKE_CASE。

## 组件规范

每个组件放在独立目录，目录内包含组件、样式和测试文件。组件必须使用 TypeScript 编写，Props 必须定义 interface 类型。禁止使用 any 类型。

## 代码风格

统一使用 ESLint 和 Prettier，提交前必须通过 lint 检查。缩进使用两个空格，不使用 Tab。单行代码不超过 100 个字符。

## Git 提交规范

提交信息使用约定式提交格式：feat（新功能）、fix（修复）、docs（文档）、refactor（重构）。例如 `feat: 新增用户卡片组件`。
